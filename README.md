# انتشار خودکار GHEBRES OFFICIAL

این مخزن هر ساعت به‌صورت خودکار روی GitHub Actions اجرا می‌شود، تصاویر سه‌زبانه (ترکی، انگلیسی، فارسی) را می‌سازد و آن‌ها را در **استوری اینستاگرام** و **کانال تلگرام** (همراه با شرح) منتشر می‌کند.

| محتوا | زمان (به وقت قبرس) | منبع |
|---|---|---|
| آب‌وهوا | ۰۸:۰۰ (امروز) و ۱۶:۰۰ (پیش‌بینی فردا) | Open-Meteo |
| داروخانه‌های کشیک | ۰۸:۰۰ و ۱۶:۰۰ | kteb.org |
| اخبار | هر ساعت از ۰۷:۰۰ تا ۲۴:۰۰ | RSS خبرگزاری‌های قبرس شمالی + نگارش با Claude |

زمان‌ها و منابع در فایل `config.yaml` قابل تغییرند. تغییر ساعت تابستانی و زمستانی خودکار لحاظ می‌شود.
GitHub گاهی اجرای زمان‌بندی‌شده را ۵ تا ۲۰ دقیقه دیرتر شروع می‌کند.

---

## راه‌اندازی (یک بار)

### ۱. ساخت مخزن در گیت‌هاب
1. در github.com یک مخزن جدید با نام `ghebres-autopost` بساز و آن را **Public** بگذار.
   اینستاگرام تصویر را فقط از یک لینک عمومی برمی‌دارد. رمزها و کلیدها در Secrets می‌مانند و دیده نمی‌شوند.
2. محتوای این پوشه را آپلود کن: **Add file ← Upload files**. پوشه `.github` را هم حتماً آپلود کن.

### ۲. ربات تلگرام
1. در تلگرام به **@BotFather** پیام بده، دستور `/newbot` را بفرست و توکن ربات را بگیر.
2. ربات را به کانال `@ghebres_official` اضافه کن و آن را **ادمین** کن، با اجازه **Post Messages**.
3. برای دریافت پیام خطا (اختیاری): به ربات خودت `/start` بفرست. بعد شناسه عددی خودت را از **@userinfobot** بگیر.

### ۳. اینستاگرام (API رسمی Meta)
1. حساب ghebres_official باید **Professional** باشد (Business یا Creator) و به یک **صفحه فیسبوک** وصل باشد:
   Instagram ← Settings ← Account type and tools.
2. در developers.facebook.com یک App از نوع **Business** بساز و محصول **Instagram** (Instagram API with Facebook Login) را به آن اضافه کن.
3. در **Graph API Explorer** با این مجوزها توکن بگیر:
   `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`, `business_management`
4. شناسه حساب اینستاگرام:
   - `GET me/accounts` شناسه صفحه فیسبوک را می‌دهد.
   - `GET {page-id}?fields=instagram_business_account` مقدار `id` را می‌دهد. این همان **IG_USER_ID** است.
5. برای اینکه توکن منقضی نشود، در **Business Settings ← System users** یک System User بساز، App و صفحه را به آن بده و یک توکن **بدون انقضا** بساز. توکن معمولی ۶۰ روز اعتبار دارد.

### ۴. کلید Claude برای نوشتن اخبار
در console.anthropic.com یک **API key** بساز. این سرویس پولی و بر اساس مصرف است.
برای ۱۸ خبر در روز، مصرف کم است. سقف هزینه را در همان کنسول تنظیم کن.

### ۵. ثبت کلیدها در گیت‌هاب
در مخزن به **Settings ← Secrets and variables ← Actions ← New repository secret** برو و این‌ها را اضافه کن:

| نام | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather |
| `TELEGRAM_CHANNEL` | `@ghebres_official` |
| `TELEGRAM_ADMIN_CHAT` | شناسه عددی خودت (اختیاری، برای هشدار خطا) |
| `IG_USER_ID` | شناسه مرحله ۳ |
| `IG_ACCESS_TOKEN` | توکن مرحله ۳ |
| `ANTHROPIC_API_KEY` | کلید مرحله ۴ |

### ۶. آزمایش
1. به **Actions ← GHEBRES autopost ← Run workflow** برو و `task = all` و `dry_run = 1` را بزن.
   در این حالت تصاویر ساخته می‌شوند ولی چیزی منتشر نمی‌شود.
2. وقتی اجرا تمام شد، از پایین صفحه فایل **output-…** را دانلود کن و تصاویر را ببین.
   در گزارش اجرا (Publish) خط `news feeds:` نشان می‌دهد کدام منبع خبری کار می‌کند. منبعی را که FAILED است در `config.yaml` اصلاح یا حذف کن.
3. اگر همه چیز درست بود، یک بار با `dry_run = 0` اجرا کن. از آن به بعد همه چیز خودکار است.

---

## کنترل روزانه
- **توقف موقت:** Actions ← GHEBRES autopost ← **Disable workflow**.
- **فقط ساختن بدون انتشار:** در `config.yaml` مقدار `dry_run: true` بگذار.
- **انتشار دستی یک مورد:** Run workflow و `task = weather` یا `pharmacy` یا `news`.
- **خطاها:** اگر مرحله‌ای شکست بخورد، پیام آن به تلگرام شخصی‌ات می‌آید (اگر `TELEGRAM_ADMIN_CHAT` را گذاشته باشی).

## نکته‌ها
- تصاویر منتشرشده در شاخه `media` مخزن نگه داشته می‌شوند و فقط ۳ روز آخر می‌مانند.
- اخبار فقط از متن منبع نوشته می‌شوند و منبع زیر هر پست ذکر می‌شود. ولی نوشته هوش مصنوعی است و ممکن است خطا داشته باشد. هر از گاهی پست‌ها را مرور کن.
- اگر kteb.org ظاهر سایتش را تغییر دهد، مرحله داروخانه خطا می‌دهد و صفحه سایت در فایل `debug/kteb.html` ذخیره می‌شود. آن را بفرست تا خواننده سایت اصلاح شود.
- اگر مخزن ۶۰ روز هیچ فعالیتی نداشته باشد، GitHub اجرای زمان‌بندی‌شده را متوقف می‌کند. انتشار روزانه خودش فعالیت حساب می‌شود.
